# Contributing to this Project

Thank you for your interest in contributing!

## Getting Started

1. Read the [Development Principles](docs/principles/README.md)
2. Review the [Architecture](docs/architecture/)
3. Check open issues in this repository

## Development Guidelines

### Code Standards

- Follow [Naming Conventions](docs/principles/naming-conventions.md)
- Implement [Access Rights](docs/principles/access-rights.md) properly
- Write tests per [Testing Principles](docs/principles/testing.md)

### Pull Request Process

1. Create a feature branch from `main`
2. Make your changes following the principles
3. Write/update tests
4. Submit PR using the template

### Commit Messages

```
{type}({scope}): {description}

{body}
```

Types: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`
